# 状态栏古诗

一个 LSPosed 模块：在系统状态栏里滚动播放古诗。

诗句从状态栏右侧进入，向左滚动，完全离开后恢复原生状态栏；停留一段时间后播放下一首。

- 包名：`io.github.rude56.poemstatus`
- 版本：1.0.0
- 系统要求：Android 13（API 33）及以上
- 作用域：仅 `com.android.systemui`（静态作用域，不可更改）
- 不申请联网权限

---

## 功能

| 功能 | 说明 |
|---|---|
| 滚动播放 | 诗句从右向左滚过状态栏，播完恢复原生内容 |
| 遮挡 | 诗句经过时隐藏其下方的状态栏内容，走过即恢复 |
| 时间停留 | 0–600 秒，结束后自动下一首 |
| 诗库 | 内置 6 首；可增删改、启停、排序；重复添加会被拒绝 |
| 导入导出 | 纯文本格式，一行一条；导入自动跳过重复 |
| 播放顺序 | 顺序循环 / 随机播放 |
| 速度 | 20–600 px/s，默认 120 |
| 作者 / 出处 | 各自独立开关；关闭后不显示，也不占位置 |
| 上下浮动 | 可选；开启后每首诗随机一个固定偏移，避免全部卡在同一高度 |
| 横屏暂停 | 默认开启 |
| 锁屏暂停 | 默认开启 |
| 白名单应用 | 名单内应用在前台时暂停并恢复系统栏 |
| 总开关 | 默认关闭，需手动开启 |
| 洞 | 可选功能：让诗句在指定区域「传送」或「隐藏」，详见下文 |

界面为 Material 3 两层结构（底部三个 tab + 二级详情页），跟随系统动态取色与深浅色。

## 安装

1. 安装 APK（需要 Root + LSPosed 2.x）：

   ```bash
   adb install -r statusbar-poem-v1.0.0-release.apk
   ```

2. 打开 **LSPosed** → 模块 → 勾选 **状态栏古诗**。
   作用域不需要手动勾选，模块已声明静态作用域，固定为系统界面。

3. 重启系统界面：

   ```bash
   adb shell su -c "killall com.android.systemui"
   ```

   也可以在设置页里点「重启系统界面」。

4. 打开 App → 开启 **启用模块** 开关（默认关闭）。

设置修改后立即生效，不需要再重启系统界面。

## 洞

「洞」是一个可选功能，用于处理状态栏上的特殊区域（例如前置摄像头挖孔）。

进入 **设置 → 洞** 可以添加若干矩形区域，每个洞有两种模式：

| 模式 | 效果 |
|---|---|
| 虫洞 | 诗句到达洞的右边缘时，瞬间从洞的左边缘出现，洞里不绘制 |
| 隧道 | 诗句位置和速度不变，经过洞的那一段被隐藏 |

洞只作用于诗句层，不影响原生状态栏内容。多个洞的位移依次累加，洞之间不允许重叠。

页面上有两个固定样例（隧道 / 虫洞各一行）实时预览两种模式的差别。

## 省电

模块常驻系统界面进程，因此空闲时能否真正休眠比峰值性能更重要。

- 帧回调按速度自适应：20 px/s 时主线程每秒只醒 20 次，高速时才到 30 fps 封顶
- 熄屏后所有定时器归零，亮屏后恢复
- 帧内零分配、零日志、零磁盘 IO、零 View 树扫描
- 暂停态不重复恢复系统栏，避免整条状态栏全量重绘
- 日志走限频闸门，长期运行不会刷满 logd

## 构建

需要 JDK 21 与 Android SDK 37。

```bash
./gradlew :app:assembleRelease
```

产物在 `app/build/outputs/apk/release/`。

运行单元测试：

```bash
./gradlew :app:testDebugUnitTest
```

---

## 已知限制

- 部分 ROM 未上报 `DisplayCutout`，此时需要手动指定洞的位置
- 状态栏为 Compose 整体绘制的系统上，遮挡通过画布裁剪实现，无法单独隐藏某一个图标
- 模块只会作用于系统界面，不会影响其他应用
